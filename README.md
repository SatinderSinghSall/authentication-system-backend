# ⚙️ Authentication System - Backend

Backend for the **Full-Stack Authentication System** built with the **MERN Stack**.

> 🚧 **Status:** Coming Soon

---

## 📖 Overview

This directory will contain the backend API for the Authentication System. It will handle user authentication, authorization, database operations, email services, and security.

Development will begin after the frontend is completed.

- Express.js
- MongoDB
- Mongoose
- JWT (JSON Web Tokens)
- Bcrypt.js
- Nodemailer
- dotenv

## 📡 Planned REST API

### Authentication

- `POST /api/auth/register`
- `POST /api/auth/login`
- `POST /api/auth/logout`
- `POST /api/auth/refresh-token`

### Password

- `POST /api/password/forgot`
- `POST /api/password/reset`

### User

- `GET /api/user/profile`
- `PUT /api/user/profile`
- `PUT /api/user/password`
